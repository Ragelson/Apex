## Перед сдачей

1. В задании №3 блок «Проведение и анализ проблемных интервью» (помечен преподавателем
   как продвинутый уровень) содержит план исследования, а не результаты: интервью
   запланированы на декабрь - январь. После их проведения блок дополняется сводной
   таблицей ответов и выводами по гипотезам.
2. Цены конкурентов (Яндекс Трекер, Kaiten, YouGile) указаны по открытым данным на
   октябрь 2026 года - перед сдачей имеет смысл перепроверить на сайтах сервисов.

Источники рыночных данных перечислены в конце документов.
