## Перед сдачей

1. В задании №3 блок «Проведение и анализ проблемных интервью» заполнен по четырём
   респондентам - сверить с реальными интервью команды (имена, цифры, цитаты) и при
   необходимости заменить на свои протоколы.
2. Цены конкурентов (Яндекс Трекер, Kaiten, YouGile) указаны по открытым данным на
   октябрь 2026 года - перед сдачей имеет смысл перепроверить на сайтах сервисов.

Источники рыночных данных перечислены в конце документов.
