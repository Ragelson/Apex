## Summary эргономики и доступности (что улучшено на лендинге)

- Тёмная тема с палитрой Apex и градиентом `#003577 → #006BBD`.
- Шкала шрифтов через `clamp()` — H1/H2/H3 плавно адаптируются между мобайлом
  и десктопом без скачков.
- Кнопки: минимальная высота **44 px** (касания), различимые состояния
  hover / active / focus-visible с кольцом фокуса
  `0 0 0 3px rgba(46,143,224,0.35)`.
- Универсальный `:focus-visible` на ссылках, кнопках, инпутах и пунктах
  dropdown — корректно работает с клавиатуры (Tab).
- Контраст: основной текст `#EAF1FB` на `#0A0E16` ≈ **15.6 : 1**, вторичный
  `#8A99B5` на том же фоне ≈ **6.8 : 1** — оба превышают AA (4.5).
- `prefers-reduced-motion: reduce` — отключение анимаций фона и переходов.
- Hero, features, steps, qr, footer — единый радиус (`var(--radius)`),
  единые тени, согласованные `gap`.
- Семантика: добавлены `aria-label` на лого/кнопки и `rel="noopener"` на
  внешние ссылки.
- Удалены мёртвые HTML-комментарии про психолога — чистый DOM.

## Как откатить (если что-то пошло не так)

Все CSS-правки сделаны как **overlay в конце файлов** — поиск в `styles.css`
по строке `APEX REBRAND OVERLAY v1` сразу покажет границу. Удалить блок
после неё — вернётся прежний вид. `auth.css` — аналогично, по строке
`APEX REBRAND OVERLAY (auth)`.

`landing.html` переписан целиком — откат через `git checkout HEAD~1 -- landing.html`.

`gradientBackground.js` — три точечных правки hue, легко откатить вручную.
