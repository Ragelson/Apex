|---|---|
| `ФАМИЛИЯ И.О. - ОСМиПА - все задания.docx` | Всё одним файлом (задания №1–№3) — основной вариант для сдачи |

## Перед сдачей

1. Переименовать файлы: `ФАМИЛИЯ И.О.` → фамилии и инициалы участников команды. Там же
   поправить строку «Команда:» на титульном листе внутри документа.
2. В задании №3 блок «Проведение и анализ проблемных интервью» заполнен по четырём
   респондентам — сверить с реальными интервью команды (имена, цифры, цитаты) и при
   необходимости заменить на свои протоколы.
3. Цены конкурентов (Яндекс Трекер, Kaiten, YouGile) указаны по открытым данным на
   октябрь 2026 года — перед сдачей имеет смысл перепроверить на сайтах сервисов.

Источники рыночных данных перечислены в конце документов.
